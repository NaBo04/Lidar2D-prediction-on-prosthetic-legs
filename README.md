# Contenido de este Repositorio :books:

    - Codgios: Contiene los códigos finales utilizados para la captura de datos, la ejecución, 
        construcción y entrenamiento de la red, el uso del dispositivo final, el entorno virtual.
        entre otros. 
    - DocumentosDeInvestigacion: Contiene los documentos externos utilizados durante el proyecto,
        como pueden ser datasheets, papers y documentos del curso.
    - DiseñosPCB: Archivos gerber de las versiones finales de las PCB usadas.
    - Entregables: Incluye los informes, presentaciones o similar, desarrollados por el equipo para
        las entregas del curso.
    - Modelos3D: Modelos diseñados para la implementación final de la muslera y la carcasa para la
        prótesis.
